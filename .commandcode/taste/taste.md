# cli
- This project runs on a Windows shell (cmd/PowerShell): avoid Unix-only CLI pipes like `| head` and `| grep` — they fail with "'head'/'grep' is not recognized"; use native tools (e.g. `findstr`) or run plain `npx tsc --noEmit` without piping. Confidence: 0.60
